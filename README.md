# cdbCONVERT downloads

Official installation packages and update metadata for cdbCONVERT, the Corporate Digital Brain file converter.

No public release is available yet. The first signed distribution is being prepared.

This repository contains release binaries and update metadata only. Application source code is maintained separately in a private repository.

## Updates

Signed distributions can check for updates in the app settings. Download and installation require your action; running jobs are allowed to finish before the app restarts. Unsigned internal test builds do not install updates from this channel.
